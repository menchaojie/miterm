# 环境安装清单（Ubuntu 22.04）

在 **Ubuntu 22.04 LTS** 上手动安装 Tauri SSH 终端 MVP 所需环境。建议按顺序执行，每步完成后做「验证」再打勾。

> **说明**：你当前机器若已配置阿里云镜像（`mirrors.aliyun.com`），`apt` 会快很多。Rust 首次安装仍可能较慢，可考虑 [rustup 国内镜像](#可选rustup-国内镜像) 或 `apt install rustc cargo`（版本可能偏旧）。

---

复制到本地记事本，装完一项勾一项：

[ ] 4. OpenSSH 测试服务（本机联调）

## 0. 系统依赖（apt）

### 安装命令

```bash
sudo apt update
sudo apt install -y \
  build-essential curl wget file pkg-config \
  libssl-dev \
  libwebkit2gtk-4.1-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev \
  libxdo-dev \
  libssh2-1-dev \
  zlib1g-dev
```

| 包名 | 作用 |
|------|------|
| `libwebkit2gtk-4.1-dev` | Tauri 2 Linux WebView |
| `libssl-dev` | OpenSSL（ssh2 / TLS） |
| `libssh2-1-dev` | Rust `ssh2` crate 链接 libssh2 |
| `zlib1g-dev` | SSH 压缩等 |
| `build-essential` | gcc/make 等编译工具 |

### 验证

```bash
pkg-config --exists webkit2gtk-4.1 && echo "webkit OK"
pkg-config --exists libssh2 && echo "libssh2 OK"
```

两项均输出 `OK` 即可进入下一步。

## 1. Rust 工具链

### 方式 A：rustup（推荐）

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# 提示时选 1) default install

source "$HOME/.cargo/env"
rustup default stable
rustup component add rustfmt clippy
```

将 `source` 写入 `~/.bashrc`（避免新开终端找不到 `cargo`）：

```bash
echo 'source "$HOME/.cargo/env"' >> ~/.bashrc
```

### 方式 B：apt（更快但版本可能较旧）

```bash
sudo apt install -y rustc cargo
```

MVP 一般够用；若 Tauri 编译报 Rust 版本不够，再改用方式 A。

### 验证

```bash
rustc --version
cargo --version
```

期望：`rustc 1.75+`（越新越好）。

### 可选：rustup 国内镜像

若 `rustup` 下载极慢，可在执行 `rustup` **之前**设置（[清华源说明](https://mirrors.tuna.tsinghua.edu.cn/help/rustup/)）：

```bash
export RUSTUP_DIST_SERVER=https://mirrors.tuna.tsinghua.edu.cn/rustup
export RUSTUP_UPDATE_ROOT=https://mirrors.tuna.tsinghua.edu.cn/rustup/rustup
```

然后再运行 `curl ... | sh`。

## 2. Node.js 20 与 pnpm

**不要**只用 Cursor/IDE 内置的 Node 跑 Tauri，请安装系统级 Node 20。

### 方式 A：NodeSource（与计划一致）

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

### 方式 B：apt 自带（22.04 多为 Node 12/18，需确认版本）

```bash
node --version   # 必须 >= 18，推荐 20
```

若版本过低，请用方式 A 或 [fnm](https://github.com/Schniz/fnm)。

### 启用 pnpm

```bash
sudo corepack enable
sudo corepack prepare pnpm@latest --activate
```

### 验证

```bash
which node    # 应为 /usr/bin/node，而非 .cursor-server 路径
node --version
pnpm --version
```

## 3. 一次性环境自检脚本

环境装完后执行：

```bash
echo "=== Rust ==="
rustc --version && cargo --version

echo "=== Node ==="
which node && node --version && pnpm --version

echo "=== Native libs ==="
pkg-config --exists webkit2gtk-4.1 && echo "webkit2gtk: OK" || echo "webkit2gtk: MISSING"
pkg-config --exists libssh2 && echo "libssh2: OK" || echo "libssh2: MISSING"
```

全部 OK 即可开始创建项目。

## 4. 本机 SSH 测试服务（联调必备）

MVP 需要能 SSH 到一台测试机，开发阶段常用 **本机 OpenSSH**。

```bash
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
sudo systemctl status ssh --no-pager
```

### 确认监听

```bash
ss -tlnp | grep ':22'
```

### 测试账号

- 使用你当前的 Linux 用户（如 `root` 或普通用户）
- 确保知道该用户的 **登录密码**（MVP 仅支持密码认证）

命令行快速测连通：

```bash
ssh -o StrictHostKeyChecking=no 你的用户名@127.0.0.1
```

能登录 shell 即表示 SSH 服务正常。

### 可选：Docker 测试容器

```bash
docker run -d --name ssh-test -p 2222:22 \
  -e PASSWORD_ACCESS=true -e USER_PASSWORD=secret \
  linuxserver/openssh-server
# 连接时 port 填 2222
```

## 5. 无图形界面 / 远程 SSH 开发时

`pnpm tauri dev` 需要 **显示服务器**（打开 GTK 窗口）。

| 场景 | 做法 |
|------|------|
| 本机有桌面 | 直接 `pnpm tauri dev` |
| SSH 到服务器、无 DISPLAY | 安装 Xvfb：`sudo apt install -y xvfb`，然后 `xvfb-run pnpm tauri dev` |
| 仅验证 Rust 编译 | `cd src-tauri && cargo build`（不弹窗） |

## 6. 创建项目前的最后检查

```bash
mkdir -p ~/projects/miterm
cd ~/projects/miterm

# 若目录为空，初始化 Tauri（交互选 React + TypeScript + pnpm）
pnpm create tauri-app . --template react-ts
pnpm install
```

首次编译会下载 Rust crates，耗时正常：

```bash
pnpm tauri dev
```

弹出空白 React 窗口 → **环境安装完成**。

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| `webkit2gtk not found` | 补装 `libwebkit2gtk-4.1-dev`，再 `pkg-config --exists webkit2gtk-4.1` |
| `failed to run custom build command` for `libssh2-sys` | 补装 `libssh2-1-dev`、`libssl-dev`、`pkg-config` |
| `cargo: command not found` | 执行 `source ~/.cargo/env` 或重开终端 |
| `node` 指向 cursor-server | 用 `/usr/bin/node`，或调整 `PATH` 让 `/usr/bin` 优先 |
| `pnpm tauri dev` 无法开窗口 | 检查 `DISPLAY`、`xvfb-run` |
| Rust 下载超时 | 使用 [rustup 国内镜像](#可选rustup-国内镜像) |

## 8. 与三平台发布的关系（备忘）

| 目标 | 构建环境 |
|------|----------|
| Linux 包 | 当前 Ubuntu 即可 `pnpm tauri build` |
| Windows 包 | 需 Windows 或 CI `windows-latest` |
| macOS 包 | 需 macOS 或 CI `macos-latest` |

在 Linux 上 **开发** 三端产品没问题；**打包** Win/mac 需另备环境，见 [开发文档](开发文档.md#后续扩展)。
